# Memory Index

- [Project: OpenPGP Decryptor](project_opengpg.md) — WPF/.NET 10 VB.NET app for managing OpenPGP profiles and encrypting/decrypting PGP messages

Notes:
- Profiles are stored in %AppData%\OpenGPG\profiles.json (unencrypted). Passphrases are not stored.
- Uses PgpCore 6.5.0 (BouncyCastle) for OpenPGP operations.
